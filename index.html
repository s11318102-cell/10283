SECTION 01 / EXHIBITION CORE

本網站介紹之 5 大核心重點

快速了解 1920 年代臺灣文化啟蒙運動的最重要脈絡

KEY POINT 01

非暴力運動轉型

西來庵事件後，抗日運動從「武裝流血流汗」轉向以「法律、文化與輿論」為武器的現代非暴力體制內抗爭。

KEY POINT 02

雙雄領導風格

對比溫和沉穩、出資支持留學與法案的「紳商」林獻堂，與充滿行動力、診斷臺灣知識貧乏的「熱血醫師」蔣渭水。

KEY POINT 03

臺灣議會請願

自1921年起進行15次請願，要求設立「臺灣議會」，主張自治權，此為臺灣史上首次規模最大的憲政民主運動。

KEY POINT 04

大眾文化啟蒙

文化協會透過巡迴「活動影劇團」、夏季學校、讀報社與《臺灣民報》，把男女平等、衛生與民主觀念推廣至全台鄉村。

KEY POINT 05

覺醒與深遠遺產

雖然因左右路線分裂與軍國主義壓迫而停擺，但啟蒙運動成功點燃「臺灣人意識」，奠定本土文學、藝術與現代公民社會基石。

SECTION 02

時代背景：從武裝抗日到文化啟蒙

大正民主浪潮與一次世界大戰後的民族自決思潮

一

武裝抗爭的終結

1915年西來庵事件後，傳統武裝抗日遭到總督府殘酷鎮壓。臺灣知識份子意識到，僅憑武力無法對抗現代化帝國，抗爭形式亟需轉型。

二

民族自決與留學生思潮

第一次世界大戰後，威爾遜提出「民族自決」。赴日留學的臺灣青年（如蔡培火、蔣渭水、林獻堂）在東京吸收近代民主政治思想，奠定文化運動基礎。

三

臺灣議會設置請願運動

自1921年起長達14年、共15次的請願，要求日本帝國議會同意在臺灣設立具民意基礎的自治議會，成為非暴力政治運動的最高峰。

歷史關鍵刻度

1921年10月17日：臺灣文化協會創立

於臺北市大稻埕靜修女子學校舉行成立大會。推舉霧峰林家紳商**林獻堂**為總理，**蔣渭水**專務理事。協會以「助長臺灣文化之發達」為宗旨，發行《臺灣民報》、舉辦文化講座、讀報社與夏季學校，開啟大規模民眾啟蒙運動。

「臺灣人現正患著『知識營養不良症』，唯有實施文化啟蒙方為對症良藥。」—— 蔣渭水《臨床講義》
SECTION 03

歷史領航者：核心人物

臺灣議會之父 / 文化頭人

林獻堂 (1881 - 1956)

出身台中霧峰林家，溫和沉穩的非暴力抗爭領袖

憑藉龐大財力與社會聲望，長年資助臺灣青年赴日留學及發起各類社會運動。倡導「漢民族文化主體性」與「溫和自治」，為臺灣議會設置請願運動的核心精神支柱。

資助臺灣民報 文協總理 創辦台中一中
臺灣的孫中山 / 行動革命家

蔣渭水 (1890 - 1931)

宜蘭出身，大稻埕大安醫院醫師，熱情強烈的行動者

臺灣文化協會實際執行核心，發表知名《臨床講義》診斷臺灣人的文化貧乏。後續成立「臺灣民眾黨」與「臺灣工友總聯盟」，將文化運動推向廣大勞工與農民。

發表臨床講義 創立臺灣民眾黨 大稻埕文化基地

SECTION 05

歷史意義與深遠影響

大眾文化啟蒙

透過巡迴活動劇團、夏季學校與通俗講座，將民主、衛生、男女平等與新文學思想帶入基層鄉鎮。

臺灣人的喉舌

《臺灣民報》成為日治時期臺灣人唯一發聲的報紙媒介，被譽為「臺灣人唯一的喉舌」，記錄了當時的抗爭與社會百態。

公民意識覺醒

從臣民思想轉變為公民意識，奠定了臺灣近代政治與社會運動的雛形，對後世民主發展影響極為深遠。

新文學與藝術

催生了臺灣新文學運動（如賴和、楊雲萍等），用文字寫下臺灣人的苦難與抵抗，開啟本土文學黃金時代。
